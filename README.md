# 热档片间（Hotbay）

影院素材分区温层：登记 → 冷热迁移 → 保留销毁 → 目录互证。

- 前端 http://127.0.0.1:6300
- API http://127.0.0.1:11300
- `docker compose up -d --build`

## 登记占用闸（臂A：以额定占用闸为准）

- 片库间额定在册分区数即硬闸：达额定则整笔登记失败，不留分区、素材段与目录增量；失败登记不计入任何读路径占用。
- 占用谓词全库唯一（分区状态「在册」），登记闸口、容量页、总览徽章、审计流水同谓词重放。
- 闸口判定与分区/素材段/目录键行写入同事务（`BEGIN IMMEDIATE` 序列化），并发抢同一库名额由库级写锁排队，不得双破硬闸；任一环节失败整笔回到登记前快照。
- 目录键行与分区册同生同死：对象键已存在即整笔拒绝，绝不静默覆盖。
- 每笔登记（成/败）落登记审计流水（`GET /api/登记审计`），含占用前→后/额定与失败原因，可与回执、容量页对照。
- 后端测试：`cd backend && python -m pytest tests/`（满容再登记、并发抢最后名额、半截失败脏写、各读面一致性）。
